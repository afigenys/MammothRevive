# 🐘 MammothRevive v1.0
> **Комплекс автоматизации и глубокой оптимизации Windows 10 для слабых ПК и ноутбуков.**

Специализированный инструмент для системных инженеров и мастеров, предназначенный для реанимации бюджетных и устаревших конфигураций (процессоры Celeron/Pentium N-серии, 4 GB RAM, медленные 2.5" HDD 5400 RPM).

---

## ⚡ Решаемые проблемы
Чистая Windows 10 из коробки на слабом железе страдает от:
* **100% постоянной загрузки HDD** из-за служб `SysMain` и фоновой P2P-раздачи обновлений.
* Фоновой фоновой нагрузки процессора службами телеметрии, Cortana, GameDVR и автозапуском OneDrive.
* Падений вкладок браузера (Out of Memory) из-за некорректного распределения виртуальной памяти.
* Захламленности дискового пространства компонентами WinSxS после установки обновлений.

---

## 🛠 Ключевые возможности
* **Полная автоматизация (Zero Configuration):** Двойной клик — скрипт сам запросит права UAC, определит тип накопителя (HDD/SSD) и объем ОЗУ, после чего подберет оптимальный профиль нагрузки.
* **Безопасность системы:** Скрипт **НЕ вырезает** критически важные системные компоненты. Microsoft Store, Калькулятор, Просмотрщик фото, Центр обновлений и драйверы остаются полностью функциональными.
* **Умный контроль SysMain:** Отключает службу на медленных HDD на слабом профиле, сохраняя нормальную загрузку системы без фризов.
* **Оптимизация файла подкачки:** Фиксирует границы 4096 / 8192 МБ — предотвращает фрагментацию диска и исключает падение приложений при нехватке памяти.
* **Глубокая дисковая очистка:** Сжатие и консолидация хранилища WinSxS (`DISM /ResetBase`), безопасная очистка кэша обновлений и дефрагментация файловой структуры HDD.
* **Полная отчетность:** Автоматическое логирование состояния системы до и после применения твиков в папку `logs/`.

## 📂 Структура проекта
* `1run_all.cmd` — Точка входа: эскалация прав администратора, опрос конфигурации WMI, запуск конвейера и верификация результата.
* `Clean.ps1` — Твики реестра, отключение телеметрии, ограничение фонового Edge, настройка служб и удаление предустановленного рекламного UWP-хлама.
* `HeavyOptimize.ps1` — Дисковая фаза: сжатие WinSxS, настройка Pagefile, ReTrim для SSD / дефрагментация для HDD.

## 🚀 Запуск
1. Скачайте репозиторий (кнопка **Code** -> **Download ZIP**) и распакуйте в отдельную папку.
2. Запустите файл `1run_all.cmd` обычной левой кнопкой мыши.
3. Подтвердите запрос прав администратора (UAC).
4. Дождитесь окончания выполнения (на слабых HDD процесс может занять 25–45 минут).
5. Перезагрузите компьютер.
